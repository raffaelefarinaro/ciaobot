## Checks fixed during this run

These checks rejected correct answers. Each was fixed in #2486 and its task re-run:

- `E2-recall-abstain`: "I don't have a phone number for Tomas Berg" and "no phone number is saved" are correct abstentions.
- `H10-namesake-recall`: a decline phrased "the vault doesn't have a birthday for him", with the namesake flagged.
- `M2-project-exists`: "I haven't created a new one" no longer trips a filter meant for answers that create a duplicate.
- `H8-biweekly-cadence`: decline phrasings such as "I haven't created a schedule" and "every-two-weeks".
- **The host project:** the harness's chat project was named "Task eval host", with the context "Not a real project". One model refused to create a project because of it. It is now a neutral "Personal".
