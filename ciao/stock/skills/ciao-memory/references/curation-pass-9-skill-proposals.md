# Pass 9: skill proposals

Review `Workspace/Skill-Proposals/`. Settle nothing: `ciao skill-proposal-remove` records a decision (implemented, or decided against), and an unattended run can make neither. You did not edit the skill, and a judgement that a proposal is not worth building is a judgement about somebody's work that a person has to make.

1. List the proposals with `ciao memory-proposals` and the routed drafts with `ciao skill-drafts`.
2. Report every one under **What needs you** with the one change it proposes.
3. You may add evidence: a new sighting of the same finding accumulates on the record, which stays queued. A settled record stays settled and is not reopened.

Proposals that belong in a bounded region stay queued too; that is the existing queue's job, not a settlement.
