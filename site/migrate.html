Moving from 1.x to 2.0

Ciaobot 2.0 is one app on the Mac and a one-line install on Linux, and it talks to Claude, Codex and OpenCode the same way. Your workspace folder, notes, vault and chats come along unchanged. This page covers how to get there and what is different once you have.

On a Mac

2.0 runs on Apple silicon Macs with macOS 14 or newer. An Intel Mac can still use Ciaobot by connecting to a server running elsewhere.

  1. Update the engine once more from Settings. A 1.x engine finds 2.0.0 in Settings → Update, as usual. This works while 2.0.0 is the latest release; an install that is still on 1.x after 2.0.1 ships has to be reinstalled by hand.
  2. Download the Ciaobot app. After the update, Home shows where to get it, or take the DMG from the latest release. From then on the app updates itself.
  3. Open it. On first launch the app finds your 1.x engine and offers to move it. If chats are still running it asks first, and you can choose Later. It then stops the old background service, starts its own engine on the same workspace and port, and moves the old engine's files to the Trash. If anything fails it puts the old engine back.

Kept: your workspace folder with its .env, notes, vault and chats, every other workspace, ~/.ciao, and any source checkout. Moved to the Trash: the old engine's tool environment and install record, its uv copy and the ~/.local/bin/ciao command (or the old Ciaobot Server.app).

Two things work differently after the move. There is no ciao command in the terminal any more. And the engine runs while the app runs: turn on Start at Login, and on a Mac mini with nobody at the keyboard also turn on automatic login, or nothing answers after a restart.

Using the older Ciaobot for Mac app (0.5)? It is offered 2.0.0 once through its own updates, then keeps itself up to date.

On Linux

A source install keeps working: update it with git as before. For a managed install, run the one-line installer as the account that owns Ciaobot:

curl -fsSL https://github.com/raffaelefarinaro/ciaobot/releases/latest/download/install.sh | sh

It installs the engine with uv and a systemd service, and ciao update runs it again to update. To move a source install's service over to it, see Linux hosting.

On Windows

2.0 does not run on Windows. Windows installs stay on 1.10 and do not update. To keep going, move your workspace folder to a Mac or a Linux machine and install 2.0 there; you can still open Ciaobot from a browser on the Windows computer.

Your agents

Ciaobot now talks to every agent through the Agent Client Protocol, using the CLI already installed on the computer. Nothing is bundled.

  • Claude: Claude Code, signed in as usual. Ciaobot installs its small adapter on first use, which needs Node 22 or newer.
  • Codex: new in 2.0. Install the Codex CLI and run codex login.
  • OpenCode: needs 2.3.2 or newer. Older versions are refused with a message that says so.

One gap to know about: when the agent wants to ask you a multiple-choice question, 2.0 does not show the question card; the agent asks in plain text instead.

What behaves differently

  • Restarts and updates no longer wait for background work, and work cut off by an update restart is not picked up again.
  • A schedule is judged on its turn's own reply; background agents that report later may arrive after the chat is archived.
  • A turn stopped by a usage limit is retried automatically every hour, for up to a week.
  • The Anthropic section of Settings is now called Claude, and has a card for trimming what Claude Code loads into every chat.
  • Ciaobot is MIT-licensed from 2.0.
