Get Ciaobot running

Connect an agent, install Ciaobot, and finish one task. About 15 minutes.

  1. Connect an agent

    Ciaobot uses an AI tool you already have. Install and sign in to Claude Code or OpenCode on the computer that will run Ciaobot.

    Claude Code setup

    On macOS or Linux:

    curl -fsSL https://claude.ai/install.sh | bash
claude auth login

    On Windows, run irm https://claude.ai/install.ps1 | iex in PowerShell, then claude auth login.

    If your terminal cannot find claude, open a new terminal or use ~/.local/bin/claude auth login. Ciaobot can find the installed CLI either way. Claude Code documentation →

    OpenCode setup

    On macOS or Linux:

    curl -fsSL https://opencode.ai/v2/install | bash
opencode auth login

    On Windows, run npm install -g @opencode/cli, then opencode auth login. OpenCode providers →

  2. Install Ciaobot

    Download Ciaobot for Mac

    Apple silicon, macOS 13+. The native app can install a local engine or connect to an existing server.

    Or install only the engine on macOS in Terminal:

    curl -fsSL https://github.com/raffaelefarinaro/ciaobot/releases/latest/download/install.sh | sh
    Open Linux install guide

    No administrator rights needed, and the engine starts when you sign in. Windows guide →

    Custom folders and important warnings

    By default your notes live in ~/Ciaobot (%USERPROFILE%\Ciaobot on Windows). To use an existing notes folder on macOS, pass --workspace:

    curl -fsSL https://github.com/raffaelefarinaro/ciaobot/releases/latest/download/install.sh | sh -s -- --workspace ~/MyNotes

    Keep the folder out of iCloud Drive, Dropbox, Google Drive and OneDrive. Sync conflicts can damage its files and Git history. Use Ciaobot's private Git backup instead.

    Ciaobot uses Git for local history. A dedicated folder is recommended: if it sits inside an existing repository, that repository's history covers it too. Nested Git repositories keep their own history. On macOS, allow Ciaobot Server to access your chosen folder when the system asks.

  3. Open Ciaobot and save your password

    The installer or Mac app opens Ciaobot, already signed in. Later, open http://localhost:8443 on the host computer.

    On Home, the Your Ciaobot card shows your folder and generated password. Save the password in your password manager; you need it on other devices. You can change it later in Settings → Access & devices.

    For a phone or another computer, open Settings → Access & devices → Other devices on the host.

  4. Finish one task, then archive it

    Type a self-contained request into the box on Home. For example:

    Give me five Italian phrases for ordering dinner, with a short pronunciation hint for each.

    Read the answer, then choose Archive. Ciaobot files useful details into your Markdown memory; anything uncertain waits for your review in Memory → To decide.

    Why start a new chat for each task?

    Short chats are easier to resume and keep the model focused on the current task. Archiving gives Ciaobot a clear point at which to extract what is worth remembering. To continue an archived topic, open the chat and choose Continue in new chat.

Help and recovery

Cost, privacy and offline use

Ciaobot is free and open source. You pay only for the AI provider you choose; a local model through OpenCode can be free and work offline.

Your notes, memory and chat history stay in your folder. Messages and the context a chat needs go to the selected AI provider. Google, web search and cloud models need an internet connection.

I cannot sign in or forgot my password

On the host, open http://localhost:8443 and choose Sign in on this computer. Then set a new password in Settings → Access & devices → PWA password.

You can also read PWA_AUTH_TOKEN= in the workspace's .env file (by default ~/Ciaobot/.env, or %USERPROFILE%\Ciaobot\.env on Windows). On macOS, press Cmd Shift . in Finder to show hidden files.

Or run ciao setup-url --workspace ~/Ciaobot on the host for a one-time sign-in link. Keep the password private.

Something is not working

Ask Ciaobot what happened; it can inspect its own logs and explain most failures. If the problem persists, report an issue on GitHub with the error and your platform.

Update, stop or uninstall

Update in Settings → General, or run the engine install command again. Stop the engine with ciao service stop; your notes stay untouched.

Windows uninstall instructions are in the Windows guide. To move from the retired macOS app, rerun the engine installer with --migrate; it keeps your workspace and removes the old app.
