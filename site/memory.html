Your second brain

How memory works

No magic and no hidden database. Ciaobot's memory is a folder of text notes plus a few simple rules about when to write and when to look. This page walks through them in the order they happen.

The short version

1. What it always knows

Every workspace has a short core memory with two parts: about you (where you live, how you like answers) and agent memory (rules and facts that matter in every chat). It's small on purpose, about a page, and it lives in a plain file called AGENTS.md in your workspace folder. Claude Code and opencode both read that file at the start of every chat.

On top of that, each message carries a small, invisible header: the workspace, the project, the project's description and today's date. If you mention someone or something Ciaobot has a note about, it adds a pointer to that note too, so the assistant knows where to look.

That's all that's loaded automatically. Everything else is looked up only when it's needed, which keeps chats fast and focused.

Facts can carry an expiry date ("the budget is €20k until the wedding"). Once the date passes, Ciaobot removes the fact before the next message, so stale facts don't linger.

2. How it finds things again

Everything else lives in your notes folder: one note per project, per person, per place, plus a learnings list. When a question needs background ("which venues are we still considering?"), the assistant searches that folder, reads the matching snippets, and tries a couple of different wordings before it says it doesn't know.

The search is a simple full-text index on your own computer (SQLite), not a black-box "semantic" database. It only searches the current workspace, so work notes never show up in a personal chat.

3. What happens when you archive a chat

Ciaobot doesn't take notes while you talk. When you archive, it works through a short checklist in the background (the chat shows tidying up):

  1. Save the conversation

    A readable copy of the chat is saved in your folder, so nothing is lost even if nothing is filed.

  2. Pick out what's worth keeping

    One AI pass reads the chat together with what Ciaobot already knows, and lists only what's new: decisions, corrections you made, new people, open to-dos. Each item has to point to the message it came from and say where it belongs: about you, a project, a person, or a lesson for next time.

  3. Update the project note

    Decisions and open to-dos are written into the project's note. As a safety net, a rewrite that would lose the note's header or delete more than half of it is refused.

  4. Check before touching the core memory

    A fact only goes into core memory automatically if you said it. Ciaobot checks the quote really is in one of your messages, that you didn't say it hypothetically or take it back later, and that it doesn't just repeat something it already knows. If it updates an older fact, the old wording is kept in a log.

  5. File it, or ask you

    New people get their own note, lessons go to the learnings list, and anything that fails a check, conflicts with what's there, or simply isn't certain becomes a suggestion for you to review.

Small talk, one-off details, and anything the assistant said on its own (rather than you) are left out. What stays is the kind of thing a good assistant would write down: "prefers morning meetings", "venue shortlist: Villa Rosa and Casa Blu", "Marco is the best man".

Where each fact goes

Kind of factWhere it's filedExample
About you, true everywhereCore memory, about you"Lives in Milan, vegetarian"
A rule for every chatCore memory, agent memory"Keep answers short; use tables for plans"
About one projectThat project's note"Wedding budget capped at €20k"
About a personA note for that person"Marco: best man, allergic to nuts"
A lesson for next timeThe learnings list"The school's calendar only accepts a work email"
Anything uncertainYour suggestions queue"Allergic to penicillin?"

A lesson that comes up repeatedly gets a counter; lessons seen three times are promoted, and one-off ones that never come back are archived after a month.

You stay in control

Suggestions wait for you

Each suggestion says where it would go. Review shows exactly how the note would change before you accept it, dismiss drops it, talk about it opens a chat to discuss it.

Every change can be undone

Each automatic change to core memory and each decision on a suggestion leaves a receipt with the before and after. The History tab lists them with an Undo button. Undo refuses if the note has changed since, so it never overwrites your newer edits.

Tell it directly

Remember that I'm allergic to penicillin.
Forget what I said about the Casa Blu venue, we dropped it.

/remember saves a fact as a suggestion; asking in plain words ("remember that…") lets the assistant write it straight away.

The nightly tidy-up

Once a night, per workspace, a routine called Workspace care goes through the queue and the notes. It files the suggestions that belong to people, projects and learnings; merges duplicates in core memory when it's getting full; and flags notes that are getting old so they can be re-checked. Once a week it also rebuilds the index and fixes broken links.

What it never does:

  • add a new fact about you to core memory (those wait for you);
  • delete a note: old or unused notes are only flagged, and you decide;
  • touch another workspace;
  • drop an important fact just to save space.

Projects you've finished

When you Complete a project, its folder moves from active to completed and it leaves the sidebar. The notes stay searchable and Ciaobot still knows the project exists, so "what did we decide about the movers last year?" still works. Restoring the project moves it back.

On a Mac: Apple Intelligence can help

On macOS 26 with Apple Intelligence switched on, Ciaobot can use Apple's on-device model for memory work, for free and without anything leaving your Mac:

  • when Ciaobot catches up on old chats that were never processed, the on-device model first answers a quick yes/no, "is there anything worth remembering here?", so a cloud model is only used where it matters;
  • you can pick Apple Intelligence as the model that extracts memories (Settings → Models). It's smaller than a cloud model, so it reads a shorter slice of long chats, and project notes are still updated with a cloud model.

It's just text files

Everything above is ordinary Markdown in the folder you picked during setup:

personal/
  AGENTS.md                  core memory (about you + agent memory)
  memory-vault/
    projects/active/…        one folder per project
    projects/completed/…     finished projects
    People/                  one note per person
    Workspace/Learnings.md   lessons learned
    Workspace/Memory-Proposals.md   your suggestions queue
Logs/Chats/                  a readable copy of every archived chat

You can open and edit it in Obsidian or any text editor, back it up like any folder, and keep using it with other AI tools, even without Ciaobot.
