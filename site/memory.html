How memory works

No magic and no hidden database. Ciaobot's memory is a folder of Markdown notes, plus a few simple rules about when to write and when to look.

The loop, on one page

Ciaobot doesn't take notes while you talk. When you archive a chat, a memory pass reads it in the background, files what it is sure about, and lists anything uncertain in Workspace/Unsure.md. Solid lines are writes to your notes; the dashed line is the unsure list.

written to your notes goes on the unsure list

Three layers

  • Always known. A short core memory about you and how you work, plus the project's description, is loaded into every chat. It lives in AGENTS.md in your workspace.
  • Looked up. Everything else is one note per project, person, place or lesson. When a question needs background, the assistant searches your notes, reads the right one, and says so when the notes don't know. Search stays inside the current workspace, so work notes never show up in a personal chat.
  • Written. After you archive a chat, facts are filed in your notes, or listed as unsure.

You can always check

  • The unsure list. What the agent could not settle goes on Workspace/Unsure.md, one line each. Tick a line to approve it, or delete it to drop it.
  • Git is the undo. The agent writes to your notes directly, and the folder is a Git repository, so every change is in its history and can be reverted.
  • Memory Map. See the whole vault as a graph of notes and links, or as a list, and open any note from it.
  • Old notes are flagged, never deleted. You decide whether to retire them, and retired notes stay readable.

The daily tidy-up

Once a day, at a time you choose, the Workspace care routine looks after each workspace:

  • It works through a checklist: it files the lines you ticked on the unsure list and leaves a report, Workspace/Care-Report.md, saying what it did and what needs you.
  • When core memory gets full, it merges duplicates and drops expired facts, and Git keeps every removed line in its history.
  • It re-checks notes that went too long without a look and flags the stale ones. When the same correction keeps coming up, it proposes a better skill as a file you can open.

It never deletes or retires a note itself: it writes a proposal file for you instead.

Back it up

Your memory lives in one folder, kept as a Git repository with the full history of every change. Connect it to a private GitHub repository and Ciaobot pushes to it automatically. Not set up yet? Choose Set up in Settings and Ciaobot walks you through it in a chat; you never need Git commands.

It's just text files

personal/ AGENTS.md memory-vault/projects/… memory-vault/People/… Workspace/Learnings.md Logs/Chats/

Open it in Obsidian or any text editor, back it up like any folder, and keep using it with other AI tools, with or without Ciaobot. Want every rule, budget and threshold? Read MEMORY_DESIGN.md, or ask Ciaobot to explain it.
