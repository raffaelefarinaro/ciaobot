Tools to pair with Ciaobot

Ciaobot does one thing: it gives you a personal agent that remembers, and a second brain you own. Everything around that, like talking instead of typing or giving the agent a browser, is left to tools you pick yourself.

Why these aren't built in

Voice models, agent browsers and usage trackers change every few months, and a better one keeps appearing. If Ciaobot shipped its own, you would be stuck with my choice and with however fast I can keep up. Instead, Ciaobot stays small and focused on memory and continuity, and you plug in whatever works best for you.

Below is what I use with my own setup. Each one is open source. You don't need to install anything by hand: copy the line under each tool into a Ciaobot chat and the agent installs it for you.

Dictation

Talking is faster than typing, especially on longer requests. A system-wide dictation app works in Ciaobot's composer and everywhere else on your computer.

FluidVoice

On-device speech-to-text for macOS, so what you say isn't sent to a server to be transcribed. An open-source alternative to Wispr Flow.

Ask Ciaobot: Install FluidVoice from https://github.com/altic-dev/FluidVoice

Keeping the computer awake

Schedules, automations and long background runs only happen while the computer running Ciaobot is awake. If it sleeps, a morning briefing doesn't arrive and a phone can't reach it.

KeepingYouAwake

A small menu-bar app that stops your Mac from going to sleep, for as long as you choose or indefinitely. Closing a laptop's lid can still put it to sleep.

Ask Ciaobot: Install KeepingYouAwake from https://github.com/newmarcel/KeepingYouAwake and start it at login

On Linux and Windows, set the computer's own power settings to never sleep.

A browser for the agent

Many tasks need a web page: checking a booking, filling a form, reading a site that has no API. An agent browser lets the agent open pages, click and read them, ideally using the accounts you are already signed in to.

ego lite

A browser built for agents such as Claude Code and Codex. It shares your logged-in browser state with the agent without taking over the window you are using.

Ask Ciaobot: Install ego lite from https://github.com/citrolabs/ego-lite and set it up for this agent

The agent acts with your accounts in that browser, so treat it like handing someone your unlocked laptop.

How much usage is left

Claude and other subscriptions limit how much you can use them in a session and in a week. A usage tracker shows how much is left before a long task stops halfway.

OpenUsage

Shows how much of each AI subscription you have used and how much is left, so you can see a limit coming.

Ask Ciaobot: Install OpenUsage from https://github.com/robinebers/openusage
