What Ciaobot does

The main things, in one line each.

Ask Ciaobot what it can do. It already knows. Every workspace ships with a guide to its own features: ask for a tour, or "can you…?" about anything, in any chat.

Workspaces, projects and chats

Separate areas of your life, projects that carry their context, and one chat per task. Home shows what needs you.

How it is organised

Code mode

Link a project to a Git repository and its chats follow the repo's own rules, while notes and memory stay in Ciaobot.

Documents side by side

Open notes, plans and tables beside the chat and comment on any passage. Office and PDF files arrive as Markdown.

Task board

Track work from To do to Done, delegate a task to an agent, and approve the result yourself.

Routines and webhooks

Work on a schedule, or started by an event from another tool. Every run ends in a chat you can read.

Memory you can check

Archived chats become Markdown notes; unsure facts wait for you, and every change can be traced.

Agents and models

File access you control

Keep the agent inside its workspace, or let it read your whole account. A permission mode on each chat sets how often it asks first.

From any device

Run it on one Mac or server and use it from your phone, tablet or another computer, installed from the browser.

Use it from anywhere

How your work is organised

Three levels, and nothing else to learn. A workspace is a life area with its own notes and memory. A project groups related chats and carries the context they share. A chat is where the work happens.
